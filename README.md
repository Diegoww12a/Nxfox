# Nxfox — Projeto fictício de estudo

> ⚠️ **Isto é um exercício de front-end.** Nada aqui é real: nenhum produto é vendido, nenhum software é distribuído, nenhum serviço é prestado. É código de estudo para portfólio, sem vínculo com qualquer jogo, servidor, empresa ou marca.

![Prévia do site](docs/preview.png)

## Sobre

Landing page e loja **demonstrativa**, construída para estudar composição de páginas, catálogo de produtos, dashboard e sistema de licenças.

O conteúdo (nomes, preços, "clientes", planos) é **fictício e ilustrativo**.

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | página principal |
| `clientes.html` | seção de clientes (demo) |
| `dashboard.html` | painel (demo) |
| `licencas.html` | licenças (demo) |

## Stack

| Camada | Tecnologia |
|---|---|
| Build | Vite |
| Estilos | Tailwind CSS + PostCSS |
| Deploy | GitHub Pages (`gh-pages`) |

## Rodar localmente

```bash
git clone https://github.com/Diegoww12a/Nxfox.git
cd Nxfox
npm install
npm run dev
```

## Build e publicação

```bash
npm run build
npm run deploy
```
